Architecture 技術亮點

Engineered for Travel Enthusiasts 專為旅行愛好者打造的先進功能

A clean, zero-build static web framework optimized for instantaneous GitHub Pages deployment. 無需任何編譯或構建步驟，純原生現代化前端架構，無縫部署至 GitHub Pages。

🧩

Decoupled 3-File Architecture 解耦三文件數據架構

All trip details are stored in config.js, site-data.js, and itinerary-data.js. Never edit HTML/CSS to change your trip. 所有行程、貨幣、地圖與文案皆收納於三個乾淨的 JS 數據檔案中，零代碼修改 HTML/CSS。

🎨

7 Luxury Theme Presets 7 款奢華色彩主題

Tailored color palettes including Alpine Emerald, Sakura Rose, Midnight Navy, Cyber Dark, and Sunset Terracotta with full Light/Dark mode. 精心配搭之高階色彩系統，包含阿爾卑斯綠、櫻花粉、午夜藍、賽博黑與日落赤陶，支援暗黑模式。

🚆

5 Transit Milestone Boards 5 大經典鐵路里程碑

Configurable railway milestone headers: Swiss SBB CFF FFS, Japanese JR Station Sign, London TfL Tube, Hong Kong MTR, and NYC MTA Subway. 可切換瑞士國鐵 SBB、日本 JR 駅名標、倫敦地鐵 Roundel、香港港鐵及紐約地鐵風格之路線看板。

🗺️

Global Vector Maps 全球向量互動地圖

Powered by MapLibre GL JS + OpenFreeMap tiles. Automatically calculates global bounding boxes for any coordinates. 採用 MapLibre GL JS 與 OpenFreeMap 向量圖磚，自動縮放全景視角，支援自定義地標圖釘。

💱

Live Currency Converter 即時匯率換算引擎

Real-time exchange rate engine powered by Open Exchange Rates API with automatic offline fallbacks. 整合即時匯率 API，一鍵動態切換港幣、美金、英鎊、歐元與日圓，並配備離線備用匯率。

📱

PWA & Offline Ready PWA 離線快取支援

Equipped with Service Worker caching and web manifest so you can access your travel itinerary even without mobile signal. 內建 Service Worker 自動快取所有資源，旅途中即使進入高山或無訊號隧道仍可流暢查閱行程。

Get Started 快速入門

How to Build Your Own Trip in 3 Steps 只需 3 步即可生成專屬旅遊指南

Leverage modern AI Copilots to draft your entire trip plan in seconds. 使用 Claude, ChatGPT 或 Copilot 配合範本提示詞，輕鬆產出高品質旅遊網站。

1

Fork Repository Fork 本專案倉庫

Click "Fork" on GitHub to create your personal copy of the Trip Planner template. 在 GitHub 上點擊 Fork 按鈕，建立屬於您個人的行程網站倉庫。

2

Prompt AI Copilot 使用 AI 生成行程數據

Copy prompts/trip-planner-prompt.md into Claude or ChatGPT with your destination and dates. 複製提示詞範本並填入目的地與日期，讓 AI 為您生成 3 個乾淨的 JS 數據檔案。

3

Deploy to GitHub Pages 一鍵發布至 GitHub Pages

Paste the 3 files into data/ and push. Your live website is instantly available worldwide! 將生成的文件貼入 data/ 目錄並提交，GitHub Actions 將自動完成發布！
